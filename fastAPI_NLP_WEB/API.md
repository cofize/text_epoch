## POST /api/analyze

Разбирает присланный текст в выбранном режиме.

**Запрос**

```json
{
  "text": "Язык устроен так, что небольшое число элементов порождает бесконечное число сообщений.",
  "mode": "epoch"
}
```

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| `text` | строка | да | от 1 до 20 000 символов |
| `mode` | строка | нет | один из режимов ниже, по умолчанию `epoch` |

**Ответ 200**

```json
{
  "ok": true,
  "result": { "…": "зависит от режима, см. ниже" },
  "meta": { "chars": 86, "mode": "epoch", "took_ms": 1.2 }
}
```

**Ответ 400** — с текстом работать нельзя: он пустой или режим неизвестен.

```json
{ "detail": "неизвестный режим: xyz. Доступны: epoch, stats, freq, longest" }
```

**Ответ 422** — данные не прошли проверку Pydantic (нет поля `text`, слишком
длинный текст). Этот ответ FastAPI формирует сам.

## Режимы анализа

| Режим | Что возвращает в `result` |
|---|---|
| `epoch` | `period` (`xviii` / `xix` / `xx`), `period_label`, `score` (0–1), `all_scores`, `uncertain`, `dated_markers` |
| `stats` | `words`, `unique`, `ttr`, `sentences`, `avg_sentence` |
| `freq` | `top` — список `{word, count}`, и `total_counted` |
| `longest` | `words` — десять самых длинных, и `max_length` |

### Режим `epoch`: пример результата

```json
{
  "period": "xviii",
  "period_label": "XVIII век",
  "score": 0.988,
  "all_scores": { "xviii": 0.988, "xix": 0.011, "xx": 0.002 },
  "uncertain": false,
  "dated_markers": [
    { "text": "Сей", "start": 0, "end": 3, "period": "xviii",
      "kind": "архаизм", "note": "указательное местоимение книжной старины" }
  ]
}
```

- `start`, `end` — позиции в исходном тексте (для подсветки); `text == source[start:end]`.
- `period` внутри признака — к какому веку этот признак «тянет».
- `uncertain: true` — признаков мало, вердикту верить нельзя; `dated_markers` может быть `[]`.

## GET /api/modes

Список доступных режимов — страница построит из него выпадающий список.

```json
{ "modes": ["epoch", "stats", "freq", "longest"] }
```
