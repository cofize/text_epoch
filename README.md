# Определитель эпохи текста

Веб-сервис, который определяет, к какому веку ближе русский текст, и подсвечивает слова, по которым это видно.

**Вход:** текст на русском языке.
**Выход:** период (XVIII, XIX или XX и позже), оценка уверенности и список датирующих признаков с позициями в тексте.

Проект состоит из двух частей, которые оцениваются раздельно:

- **модель** (курс «Автоматическая обработка естественного языка»): данные из открытых библиотек и корпусов, обучение, метрики, анализ ошибок;
- **веб-сервис** (курс «Основы web-программирования»): API на FastAPI и страница, которая показывает результат.

Части связаны одной функцией `predict(text)`. Пока модель не готова, вместо неё работает заглушка.

> **Статус.** Сервис работает на заглушке: она ищет слова из заранее составленного списка и не является обученной моделью. Об этом сообщает поле `"stub": true` в ответе и плашка на странице. Метрики качества относятся только к настоящей модели.

## Как это выглядит

Страница состоит из поля ввода и блока результата:

- вердикт («XIX век») и уверенность;
- полоса вероятностей по трём периодам;
- исходный текст, где датирующие слова подсвечены цветом своего периода;
- список признаков с пояснением. Клик по признаку прокручивает к нему в тексте.

Если признаков в тексте нет, страница пишет «Не удалось определить» вместо случайного вердикта.

## Быстрый старт

Нужен Python 3.9 или новее.

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

- сайт: http://127.0.0.1:8000/
- документация и ручная проверка API: http://127.0.0.1:8000/docs

Проверка окружения до запуска: `python check_env.py`.
Проверка работающего сервиса (в другом терминале): `python test_api.py`.

## API

Подробный контракт в [`API.md`](API.md). Кратко:

`POST /api/analyze`

```json
{ "text": "Барин приказал подать экипаж, и лакей побежал на станцию.", "mode": "epoch" }
```

```json
{
  "ok": true,
  "result": {
    "period": "xix",
    "period_label": "XIX век",
    "score": 0.95,
    "all_scores": { "xviii": 0.03, "xix": 0.95, "xx": 0.02 },
    "uncertain": false,
    "stub": true,
    "dated_markers": [
      { "text": "Барин", "start": 0, "end": 5, "period": "xix",
        "kind": "реалия", "note": "реалия дореволюционной России" }
    ]
  },
  "meta": { "chars": 56, "mode": "epoch", "took_ms": 1.1 }
}
```

- `start` и `end` — позиции признака в исходном тексте, по ним страница строит подсветку.
- `uncertain: true` — признаков мало, вердикту верить нельзя.
- Текст: от 1 до 20 000 символов.

| Эндпоинт | Что делает |
|---|---|
| `POST /api/analyze` | определить эпоху (режим `epoch`) или посчитать статистику (`stats`, `freq`, `longest`) |
| `GET /api/modes` | список режимов |
| `GET /api/health` | проверка, что сервис жив, и число запросов |
| `GET /api/history?limit=10` | последние запросы, новые сверху |
| `GET /` | страница сайта |

Ошибки: `400` с текстом причины в поле `detail` (пустой текст, неизвестный режим), `422` при неверном формате запроса.

## Периоды

| Код | Период |
|---|---|
| `xviii` | XVIII век |
| `xix` | XIX век |
| `xx` | XX век и позже |

Тексты в корпусах и библиотеках приведены к современной орфографии, поэтому признаки эпохи ищутся в лексике и речевых оборотах: архаичные служебные слова, этикет, реалии, советизмы, современная лексика.

## Как подключить настоящую модель

В `nlp.py` заменить одну строку:

```python
from epoch_stub import predict   →   from model import predict
```

Функция `predict(text)` должна вернуть словарь с полями `period`, `score` и `dated_markers` (формат выше). Сервер и страница при этом не меняются. Поле `stub` настоящая модель не возвращает, и плашка про заглушку исчезает сама. Если модель не умеет объяснять решение по словам, `dated_markers` может быть пустым списком.

## Ограничения

- Заглушка знает только слова из своего списка и не оценивает стиль и синтаксис. На произвольном отрывке без таких слов она ответит «не удалось определить».
- Определяется век целиком, без более точной датировки.
- История запросов хранится в памяти процесса и пропадает при перезапуске.
- Поддерживается только русский язык.
