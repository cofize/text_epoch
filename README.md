# text_epoch — определение жанра и периода русского текста

Проект исследует автоматическую датировку русскоязычных текстов по двум задачам:
1. определить жанр (`поэзия`, `проза`, `публицистика`);
2. определить исторический период с шагом 25 лет.

Порядок всегда такой: **сначала жанр, потом период внутри жанра**; слова-маркеры
берутся из словаря именно этого жанра.

Текущая экспериментальная шкала периода: `1800–1824`, `1825–1849`, `1850–1874`,
`1875–1899`, `1900–1924`, `1925–1949`. В фактическом наборе данных последняя
корзина начинается с 1925 года; отбор исходных страниц в скрипте ограничен 1944 годом.

> **Текущий статус.** В репозитории есть датасет `train/val/test`, словари маркеров,
> отчёт по шести вариантам моделей, код обучения и веб-сервис. Веса обученных моделей
> (около 1,4 ГБ) в Git не хранятся: они лежат на Google Диске, ссылка в разделе
> [«Модель»](#модель). Сервис работает в двух режимах:
> **с моделью** (папка `model_run` скачана) период оценивает дообученный `rubert`;
> **без модели** это заглушка: жанр определяется по признакам текста, период — по
> сумме весов найденных слов-маркеров. И там и там слова-маркеры подсвечиваются
> в тексте по словарю выбранного или найденного жанра.

## Данные

Источник — русская Викитека (`ru.wikisource.org`), дамп `ruwikisource.xml.bz2` (1,94 ГБ).
Жанр и год берутся из категорий и шаблонов, которые заполняют волонтёры Викитеки;
собственной ручной разметки нет. Тексты находятся в общественном достоянии.

### Принятые решения

| Решение | Параметры и причина |
|---|---|
| Границы | 1800–1944; шаг периода 25 лет |
| Что исключено | переводы (год оригинала не равен году перевода), конфликты годов, энциклопедии и словари, страницы короче 500 символов, страницы без жанра или с несколькими жанрами |
| Орфография | `ѣ→е`, `ѳ→ф`, `і` и `ѵ→и`, снят конечный `ъ`, иначе граница «до и после 1918 года» стала бы слишком лёгкой подсказкой; флаг `old_orth` сохранён (26,1 % фрагментов) |
| Длина фрагмента | проза и публицистика около 1 800 символов (1 000–3 000), режем по предложениям; поэзия около 800 (300–1 500), режем по строкам. В среднем 250 токенов для прозы и 105 для поэзии, что укладывается в окно 512 токенов |
| Лимиты | 12 фрагментов со страницы, 40 на произведение, 300 на автора (группу), чтобы длинные книги и плодовитые авторы не доминировали |
| Группа | автор, а если автора нет, то произведение; имена автора нормализуются |
| Разбиение | около 80 / 10 / 10 по группам: все тексты одного автора и все его произведения попадают в одну выборку, пересечений нет, это проверяется в коде |
| Баланс | каждая ячейка «жанр × период» приведена к размеру самой малой: 401 фрагмент (321 train, 40 val, 40 test; в ячейке «проза 1800–1824» 323 / 40 / 38) |

Классы жанра: поэзия, проза, публицистика. Периоды задаются 25-летними корзинами
с началами `1800`, `1825`, `1850`, `1875`, `1900`, `1925`. Единица данных —
фрагмент текста. Подробности и ограничения описаны в

### Подготовка датасета и воспроизводимость

Порядок этапов, если подготовлены исходные `meta.jsonl` и дамп Викитеки:

1. `01_select.py` — фильтрация и отбор страниц, запись `selected.csv`.
2. `02_extract.py` — чтение XML-дампа, очистка вики-разметки, нормализация
   орфографии и нарезка фрагментов, запись `fragments.jsonl`.
3. `03_build_dataset.py` — объединение фрагментов с метаданными, лимиты,
   балансировка ячеек «жанр × период», разбиение по группам, запись трёх файлов
   `train.jsonl`, `val.jsonl`, `test.jsonl`.
4. `04_marker_candidates.py` — словари маркеров отдельно для каждого жанра.

Примеры команд и параметры приведены в
[`создание датасета/README.md`](создание%20датасета/README.md).
Полный цикл нельзя запустить только по содержимому репозитория: исходный дамп,
`meta.jsonl`, `selected.csv` и `fragments.jsonl` не приложены.

## Словари маркеров

Словарь строится отдельно для каждого жанра и только по обучающей выборке (`train`):
слово сравнивается с другими периодами того же жанра.

1. Берутся слова, которые встречаются не менее 20 раз, и в периоде не менее 20 раз.
2. Сильный кандидат: в своём периоде минимум вдвое чаще, чем в остальных; встречается
   минимум в 15 произведениях и у 8 авторов периода; на одного автора приходится не более 40 %
   употреблений.
3. Убирается «не язык эпохи»: имена собственные, следы орфографии (`котораго`, `ея`),
   редакторская разметка (`стр`, `рукописи`, `варианты`) и слова о самой литературе.
4. Проверка на `val`: подтверждается 71–74 % кандидатов.

| Жанр | Слов от 20 | Кандидатов | В словаре | Подтверждается на val |
|---|---:|---:|---:|---:|
| Поэзия | 1 136 | 43 | 43 | 74 % |
| Проза | 2 594 | 179 | 171 | 71 % |
| Публицистика | 2 573 | 137 | 132 | 73 % |

Описание файлов и примеры маркеров: [`markers/README.md`](markers/README.md).

## Результаты обучения и сравнение моделей

В `reports/model_comparison.html` сохранён отчёт по тестовой выборке:
718 фрагментов из 551 произведения. Сравнивались `rubert`, `rubert_dict`,
`tfidf`, `tfidf_dict`, `xlmr`, `xlmr_dict`; суффикс `_dict` означает добавку
словаря маркеров к вероятностям базовой модели.

Главная метрика — QWK периода (квадратично взвешенная каппа Коэна): она учитывает
порядок периодов, и ошибка на два периода штрафуется сильнее, чем на один. Целевое
значение из карточки проекта — 0,60–0,75.

| Модель | QWK по произведениям (95 % ДИ) | QWK по фрагментам |
|---|---|---:|
| **rubert** | **0.800** (0.73–0.85) | **0.818** |
| rubert_dict | 0.790 (0.73–0.84) | 0.808 |
| tfidf_dict | 0.762 (0.69–0.81) | 0.775 |
| xlmr | 0.748 (0.67–0.80) | 0.761 |
| xlmr_dict | 0.726 (0.65–0.79) | 0.738 |
| tfidf | 0.707 (0.63–0.77) | 0.732 |

У лучшей модели `rubert` (по произведениям): жанр определяется верно в 93,1 % случаев,
период точно в 53,0 %, в пределах соседнего периода в 89,7 %, средняя ошибка около
15 лет. Эффект словаря: для `tfidf` +0.055 (значим), для `rubert` −0.010 и для `xlmr`
−0.022 (доверительные интервалы включают 0, значимого эффекта нет). Подробная сводка,
матрицы ошибок и разрезы по жанрам находятся в
[`reports/model_results.md`](reports/model_results.md).

**Интерпретация осторожная:** отчёт отдельно предупреждает о сильном различии
доли `old_orth` между периодами (от 38 % до 5 %). Несмотря на нормализацию старой
орфографии, эта переменная может быть связана с эпохой и служить косвенной подсказкой.
Нельзя утверждать, что модель определяет именно стилистические особенности, пока не
проведена дополнительная проверка на контролируемых подвыборках. Годы, упомянутые
в самих текстах, не маскировались.

**Определение жанра в сервисе.** При ручной проверке на произвольных текстах жанровая
сеть модели ошибалась заметно чаще, чем простая оценка по признакам текста (длина строк,
диалоги, глаголы прошедшего времени, отвлечённая лексика). Количественно это не оценивалось,
поэтому по умолчанию сервис определяет жанр по признакам текста, а период — моделью;
жанр всегда можно выбрать вручную. Жанровую сеть включает переменная `EPOCH_GENRE=model`.

## Обучение

Код обучения и оценки находится в [`обучение/era_pipeline.py`](обучение/era_pipeline.py):
классы `TransformerModel` (rubert, xlmr), `TfidfModel` и `BoostedModel` (добавка словаря),
метрики. Модель состоит из двух сетей: жанр определяется по тексту, а период — по паре
«жанр, текст», поэтому период зависит от жанра. Параметры трансформеров по умолчанию:
3 эпохи, скорость обучения 2e-5, батч 8 с накоплением 2, длина входа 512, зерно 42.
Готового скрипта запуска обучения в репозитории нет.

## Модель

Веса (`rubert` и `xlmr`, около 1,4 ГБ для двух сетей) слишком велики для GitHub, поэтому
они лежат на Google Диске:
[model_run](https://drive.google.com/drive/folders/1LLHrYofftgc2RpjRvbIEPY6sAuZKhza9?usp=sharing).
Нужны только `meta.json` и папка `model/` (`preds_*.jsonl` для работы не нужны). Положите
их в `epoch_service/model_run/`, так сервис подхватит модель сам. Подробнее: раздел «Модель»
в [`epoch_service/README.md`](epoch_service/README.md).

## Веб-сервис

Страница и API: вставляете текст, при желании выбираете жанр, получаете жанр, период,
оценку и слова-маркеры, подсвеченные прямо в тексте; при наведении на слово видно, на какую
эпоху оно указывает и во сколько раз чаще встречается в ней, чем в других эпохах этого жанра.

Требуется Python 3.10 или новее. Для режима без модели внешние библиотеки не нужны:

```bash
cd epoch_service
python -m service --port 8000
```

Откройте http://127.0.0.1:8000/ . С обученной моделью сначала скачайте `model_run` (см. выше)
и установите зависимости:

```bash
pip install -r requirements-nn.txt
python -m service --port 8000
```

В консоли видно, что загрузилось: `модели: rubert (model_run)` или `модели: stub-0.1 (заглушка)`.
Состояние сервиса также показывает http://127.0.0.1:8000/api/health .

Словари маркеров лежат в `epoch_service/dictionaries/` (формат `dict_<жанр>_form.json`, их создаёт
шаг 4). Периоды словарей и модели могут отличаться: слово подсвечивается, если его эпоха пересекается
с найденным периодом. Тесты:

```bash
cd epoch_service
python -m unittest discover tests -v
```

## Ограничения и планы

- Сервис и словари используют точные словоформы без лемматизации.
- Тексты короче 1000 знаков оцениваются менее надёжно (сервис предупреждает).
- Остатки дореформенной орфографии (`-аго`, `-ыя`, `ея`) в словари по умолчанию не попадают.
- Тестовая выборка небольшая (718 фрагментов, 551 произведение).

Что ещё требуется:

- количественно сравнить определение жанра по признакам текста и жанровой сетью на `test`;
- проверить влияние `old_orth` на качество и замаскировать годы в самих текстах;
- дедупликация данных;
- расширить корпус на 1950–2026 годы;
- добавить скрипт запуска обучения и зафиксировать точные версии зависимостей;
- согласовать скрипты сборки датасета с `05_Dataset_card.md`;
- обновить `04_Контракт_API.md` под актуальный ответ сервиса.
