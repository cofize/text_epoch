# text_epoch: автоматический определитель эпохи текста

Система, которая по русскому тексту определяет, к какой эпохе он относится, и показывает признаки, по которым сделан вывод.

|  |  |
|---|---|
| **Вход** | `{text}` |
| **Выход** | `{genre, period, score, dated_markers}`: жанр, период, оценка уверенности, датирующие признаки с позициями в тексте |
| **Трек** | А: классификация (тема из банка, А5) |
| **Основная метрика** | QWK (взвешенная каппа Коэна), целевое значение 0,60–0,75 |

> **Статус.** Работает веб-сервис с демонстрационной заглушкой вместо модели. Модель ещё не обучена, метрики не измерены. Подробности в разделе «Статус».

## Зачем это нужно

- исследователям и филологам: быстро уточнить эпоху текста и увидеть, какие слова на это указывают;
- архивам: как помощь при каталогизации;
- экспертам: как предварительная проверка датировки;
- разработчикам: как инструмент отбора текстов нужной эпохи для своих корпусов.

## Почему не готовая модель

Единственная найденная готовая модель, [ChangeIsKey/text-dating](https://huggingface.co/ChangeIsKey/text-dating) (RoBERTa-large, предсказывает десятилетие), обучена на английских текстах. На 20 русских примерах она показала низкую и нестабильную точность, особенно на ранних текстах, поэтому нужна своя модель на русском материале. Обзор существующих решений, моделей и наборов данных: [`02_Обзор_решений.md`](02_Обзор_решений.md).

## Данные

Основной источник: диахронические корпуса Национального корпуса русского языка (НКРЯ) с ручной разметкой исследователей. Планируемый объём около 100 тыс. вхождений, доступ к датасету запрошен.

Три периода, на которые разбиты диахронические корпуса НКРЯ:

| Период | Годы |
|---|---|
| досоветский | 1700–1916 |
| советский | 1918–1991 |
| постсоветский | 1992–2016 |

Корпуса НКРЯ содержат предложения без привязки к конкретным датам, и орфография в них приведена к современной. Поэтому признаки эпохи нужно искать в лексике, морфологии и речевых оборотах, а не в написании.

Дополнительные источники для обучения и проверки: RuHeritage-Corpus, корпус Тайга (тексты XX–XXI веков), TOROT Treebank (древнерусские и церковнославянские тексты).

## Метрика

Основная метрика: **QWK**. Время порядковое: перепутать соседние эпохи менее критично, чем далёкие, а QWK это учитывает и устойчива к дисбалансу классов, ожидаемому в историческом корпусе.

- целевое значение: 0,60–0,75;
- порог неработоспособности: 0,20, если модель путает далёкие эпохи чаще, чем соседние.

Модель и веб-сервис связаны одной функцией `predict(text)`. Пока модели нет, её место занимает заглушка, которая заменяется одной строкой импорта.

## Веб-сервис

Сервис принимает текст и показывает вердикт, полосу вероятностей по периодам и текст с подсвеченными датирующими словами. Запуск (Python 3.9+):

```bash
cd web
pip install -r requirements.txt
uvicorn main:app --reload
```

Сайт откроется на http://127.0.0.1:8000/, документация API на http://127.0.0.1:8000/docs. Контракт API описан в `web/API.md`.

Пример ответа `POST /api/analyze`:

```json
{
  "ok": true,
  "result": {
    "period": "xix",
    "score": 0.95,
    "stub": true,
    "dated_markers": [
      { "text": "Барин", "start": 0, "end": 5, "period": "xix",
        "kind": "реалия", "note": "реалия дореволюционной России" }
    ]
  },
  "meta": { "chars": 56, "mode": "epoch", "took_ms": 1.1 }
}
```

**О заглушке.** Сейчас вместо модели работает функция, которая ищет в тексте слова из заранее составленного списка (архаизмы, этикет, реалии, советизмы, современная лексика). Это не обученная модель: на тексте без таких слов она отвечает «не удалось определить». Её ответы помечены полем `"stub": true`, а страница показывает соответствующую плашку. Метрики качества относятся только к настоящей модели.
