# text_epoch — определение жанра и периода русского текста

Проект исследует автоматическую датировку русскоязычных текстов по двум задачам:
1. определить жанр (`поэзия`, `проза`, `публицистика`);
2. определить исторический период с шагом 25 лет.

Текущая экспериментальная шкала периода: `1800–1824`, `1825–1849`, `1850–1874`,
`1875–1899`, `1900–1924`, `1925–1949`. В фактическом наборе данных последняя
корзина начинается с 1925 года; отбор исходных страниц в скрипте ограничен 1944 годом.

> **Текущий статус.** В репозитории есть датасет `train/val/test`, словари
> маркеров, экспериментальный HTML-отчёт по шести вариантам моделей и учебный
> FastAPI-интерфейс. Однако код обучения и веса обученных моделей в приложенном
> архиве отсутствуют. Веб-приложение использует новую словарную заглушку на основе трёх жанровых JSON-словарей из `markers/`. Пользователь сначала выбирает жанр, затем сервис датирует текст по словарю выбранного жанра. Это не обученная модель из экспериментов. Поэтому результаты
> экспериментов нельзя считать подключёнными к сайту.

## Данные

Источник — русская Викитека (`ru.wikisource.org`), дамп `ruwikisource.xml.bz2`.
Скрипты ориентированы на каталог метаданных `meta.jsonl`, полученный на более
раннем этапе подготовки корпуса. Сам `meta.jsonl`, исходный XML-дамп и промежуточные
`selected.csv` / `fragments.jsonl` в этом архиве не приложены.

В архиве находятся готовые выборки:

| Файл | Фрагментов |
|---|---:|
| `создание датасета/dataset.jsonl/train.jsonl` | 5 780 |
| `создание датасета/dataset.jsonl/val.jsonl` | 720 |
| `создание датасета/dataset.jsonl/test.jsonl` | 718 |
| **Всего** | **7 218** |

Классы жанра: поэзия, проза, публицистика. Периоды задаются 25-летними корзинами
с началами `1800`, `1825`, `1850`, `1875`, `1900`, `1925`. Единица данных —
фрагмент текста. Подробности и ограничения описаны в
[`05_Dataset_card.md`](05_Dataset_card.md).

### Важное замечание о воспроизводимости датасета

В архиве есть готовые JSONL-выборки, но скрипты подготовки не полностью
воспроизводят их текущую версию без дополнительных исходных файлов и уточнения
параметров. В частности, `03_build_dataset.py` в архиве пишет один файл с полем
`split`, а не три файла; его код также не содержит заявленного в старой карточке
лимита на 300 фрагментов на автора/группу. Перед повторной сборкой датасета
необходимо синхронизировать скрипт, карточку датасета и фактический пайплайн,
которым были получены приложенные `train.jsonl`, `val.jsonl`, `test.jsonl`.
Не следует считать старые описания параметров автоматически соответствующими
текущему коду.

## Результаты обучения и сравнение моделей

В `reports/model_comparison.html` сохранён переданный отчёт по тестовой выборке:
718 фрагментов из 551 произведения. Сравнивались `rubert`, `rubert_dict`,
`tfidf`, `tfidf_dict`, `xlmr`, `xlmr_dict`.

Лучший результат по QWK периода на уровне произведений показал `rubert`:
**0.800** (95% ДИ: 0.73–0.85). При оценке отдельных фрагментов QWK составил
**0.818** (95% ДИ: 0.75–0.87). Подробная сводка, сравнение словарной добавки,
матрицы ошибок и разрезы по жанрам находятся в
[`reports/model_results.md`](reports/model_results.md).

**Интерпретация осторожная:** отчёт отдельно предупреждает о сильном различии
доли `old_orth` между периодами. Несмотря на нормализацию старой орфографии,
эта переменная может быть связана с эпохой и служить косвенной подсказкой.
Нельзя утверждать, что модель определяет именно стилистические особенности,
пока не проведена дополнительная проверка на контролируемых подвыборках.

## Быстрый запуск веб-интерфейса

Требуется Python 3.10 или новее. Команды выполняются из папки веб-приложения:

```bash
cd fastAPI_WEB
python -m venv .venv
```

Активация окружения:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate
```

Установка зависимостей и запуск:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте:
- сайт: http://127.0.0.1:8000/
- Swagger UI: http://127.0.0.1:8000/docs
- проверка состояния: http://127.0.0.1:8000/api/health

Остановка сервера: `Ctrl+C`.

**Текущий сценарий:** сначала вручную выбирается жанр (поэзия, проза или публицистика), затем вводится текст. Сервер загружает соответствующий JSON-словарь из `markers/`, ищет точные словоформы и суммирует веса маркеров по периодам. Периоды словарей: 1800–1849, 1850–1899, 1900–1924 и 1925–1944. Это демонстрационная эвристика, а не одна из шести обученных моделей из отчёта. Подробности — в [`fastAPI_WEB/README.md`](fastAPI_WEB/README.md).

## Проверка веб-приложения

При работающем сервере в другом терминале:

```bash
cd fastAPI_WEB
python test_api.py
```

Проверка окружения:

```bash
python check_env.py
```

Тесты обращаются к уже запущенному серверу. `check_env.py` проверяет наличие
основных библиотек и возможность импортировать FastAPI-приложение.

## Подготовка датасета

Порядок этапов, если подготовлены исходные `meta.jsonl` и дамп Викитеки:

1. `01_select.py` — фильтрация и отбор страниц, запись `selected.csv`.
2. `02_extract.py` — чтение XML-дампа, очистка вики-разметки, нормализация
   орфографии и нарезка фрагментов, запись `fragments.jsonl`.
3. `03_build_dataset.py` — объединение фрагментов с метаданными, ограничения
   по произведениям, балансировка ячеек «жанр × период» и присвоение split.

Примеры команд и параметры приведены в
[`создание датасета/README.md`](создание%20датасета/README.md).
Полный цикл нельзя запустить только по содержимому архива: отсутствуют исходный
дамп и `meta.jsonl`.
