# Словари датирующих маркеров

Папка содержит подготовленные словари маркеров для трёх жанров:
поэзии, прозы и публицистики. Это данные для экспериментов с добавлением
лексических признаков к классификаторам; сами файлы не обучают модель
и не запускают анализ текста.

## Состав папки

| Файл | Назначение |
|---|---|
| `markers_поэзия_form.csv` | таблица маркеров для поэзии |
| `markers_проза_form.csv` | таблица маркеров для прозы |
| `markers_публицистика_form.csv` | таблица маркеров для публицистики |
| `dict_поэзия_form.json` | словарь маркеров поэзии в JSON |
| `dict_проза_form.json` | словарь маркеров прозы в JSON |
| `dict_публицистика_form.json` | словарь маркеров публицистики в JSON |
| `dropped_поэзия_form.csv` | исключённые маркеры поэзии |
| `dropped_проза_form.csv` | исключённые маркеры прозы |
| `dropped_публицистика_form.csv` | исключённые маркеры публицистики |

## Форматы

CSV предназначены для просмотра и анализа в табличном редакторе или Python
(`pandas`). JSON хранит словарное представление для программного чтения.
Файлы `dropped_*.csv` фиксируют маркеры, которые не вошли в итоговые словари.

Пример чтения JSON:

```python
import json

with open("dict_поэзия_form.json", encoding="utf-8") as f:
    markers = json.load(f)

print(type(markers))
print(len(markers))
```

Пример чтения CSV:

```python
import pandas as pd

df = pd.read_csv("markers_поэзия_form.csv")
print(df.head())
print(df.columns.tolist())
```

## Как используются словари в эксперименте

В переданном отчёте сравниваются пары:
- `rubert` / `rubert_dict`;
- `tfidf` / `tfidf_dict`;
- `xlmr` / `xlmr_dict`.

Суффикс `_dict` означает вариант базовой модели с добавкой словарных маркеров.
В отчёте указано, что словарная добавка улучшила QWK у TF-IDF, но не дала
улучшения у RuBERT и XLM-R на тестовой выборке. Подробные цифры находятся
в [`../reports/model_results.md`](../reports/model_results.md).

## Воспроизводимость и ограничения

В этой папке нет скрипта, который создаёт CSV/JSON-словари, нет описания
полного алгоритма извлечения маркеров и нет исполняемого адаптера, который
подключает эти JSON-файлы к моделям. Поэтому README описывает назначение
и доступное содержимое, но не приписывает словарям неизвестный способ
построения. Для полного воспроизведения нужно добавить код формирования
словарей и конфигурацию интеграции с каждой моделью.
