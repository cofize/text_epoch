## Эндпоинт

**Адрес:** /analyze (базовый URL сервиса уточняется при развёртывании)
**Метод:** POST 

## Запрос

```json
POST /analyze
Запрос:
{ "text": "строка" }
```

| Поле | Тип | Обязательно | Описание | Ограничения |
|---|---|---|---|---|
| text | string | да | входной текст пользователя | по длине символов |

## Ответ при успехе

```json
{
  "genre": "художественный",
  "period": "1900-1950",
  "score": 8.0,
  "dated_markers": [
    { "text": "оный", "start": 42, "end": 46, "category": "лексика" }
]
}
```

| Поле | Тип | Описание |
|---|---|---|
| genre | string | жанр введённого текста, одно значение из закрытого списка |
| period | string | примерная дата написания текста |
| score | number | уверенность модели в определённом периоде, от 0 до 1 (чем больше, тем увереннее) |
| dated_markers | array | 	языковые маркеры, на основании которых определена эпоха; может быть пустым массивом [] |

Элемент dated_markers:
| Поле | Тип | Описание |
|---|---|---|
| text | string | 	слово или форма, оказавшие влияние на решение |
| start | integer | позиция начала во входном тексте (номер символа, с нуля) |
| end | integer | позиция конца (не включительно), нужна интерфейсу для подсветки |
| category | string | тип маркера: орфография, лексика, морфология, синтаксис |

## Ответ при ошибке

```json
{ "error": "код", "message": "текст для пользователя" }
```

| Ситуация | Код | HTTP |
|---|---|---|
| Пустой текст | `empty_text` | 400 |
| Текст длиннее допустимого | `text_too_long` | 400 |
| Текст короче допустимого | text_too_short | 400 |
| Некорректный запрос (нет поля text, не строка, невалидный JSON) | invalid_request | 400 |
| Текст не на русском языке | unsupported_language | 422 |
| Модель временно недоступна | model_unavailable | 503 |
| Внутренняя ошибка сервер | internal_error | 500 |


## Ограничения

**Максимальная длина текста:** 10 000 символов
**Минимальная длина текста:** 50 символов
**Ожидаемое время ответа:** до 5 секунд
**Нужен ли индикатор загрузки в интерфейсе:** да
