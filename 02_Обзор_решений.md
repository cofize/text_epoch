# Обзор решений

## Существующие решения

| № | Источник | Подход | Материал | Результат | Чем не подходит нам |
|---|---|---|---|---|---|
| 1 |https://textometr.ru/text-style |определяет стиль текста по признакам (как я поняла: каких признаков больше, такой и текст)| |выдаёт признаки, почему это именно этот стиль с примерами из текста|определяет только стиль, не эпоху (но уже хорошо!)|
| 2 |**Interactive System for Reasoning about Document Age** (Jatowt & Campos, CIKM 2017)|Интерактивная система: вероятность даты на основе частот n-грамм из Google Books Ngrams. Выводит распределение вероятностей и «доказательства» (топ n-грамм, объясняющие пики).|Англоязычные тексты.|Оценивает год создания документа, показывает вероятностное распределение по годам.|*Прототип не выложен* — только постер и статья.  Нет доступа к коду. Ориентирован на английский язык. Нет разделения по стилям. |
| 3 |**ChangeIsKey/text-dating** (HuggingFace)|Fine-tuned RoBERTa-large. Классификация предложений по десятилетиям (1700–2021)|Англоязычные исторические тексты (OED).|Предсказывает десятилетие написания предложения. Метрика — weighted F1. |Только английский язык. Не учитывает стиль.|
| 4 |**The Influence of Different Stylometric Features on the Classification of Prose by Centuries** (Lagutina et al., FRUCT 2020) |Сравнение стилометрических признаков: символьные, словесные, ритмические. Классификаторы: Random Forest, AdaBoost, LSTM, GRU|Тексты на английском, русском, французском языках (1815–2019) |Комбинация ритмических и низкоуровневых признаков значимо улучшает классификацию по векам| Нет разделения по стилям как отдельного этапа. Нет интерактивной системы. Но напрямую подтверждает, что стилометрические признаки различаются по эпохам.|



## Готовые модели

| Модель | Что делает | Результат на нашем материале |
|---|---|---|
|ChangeIsKey/text-dating https://huggingface.co/ChangeIsKey/text-dating |Fine-tuned RoBERTa-large, предсказывает дату с точностью до десятилетий. Обучена на исторических текстах с 1700 по 2021 год |доступна только для английского, для русского показывает очень непостоянную точность определения|

## Готовые наборы данных

| Набор | Объём | Разметка | Применимость |
|---|---|---|---|
|RuHeritage-Corpus|~9 292 произведения|Есть группировка по периодам (Золотой и Серебряный века)|Можно использовать как источник текстов для обучения. Нужно добавить стилевую разметку|
|Национальный корпус русского языка (НКРЯ) Диахронические корпуса |250 млн (суммарно)|Диахронические наборы данных охватывают три периода (1700—1916, 1918—1991 и 1992—2016 годы) и соответствуют приблизительно трём историческим периодам развития общества и русского языка Нового времени («досоветскому», «советскому» — включая, разумеется, и тексты эмиграции, — и «постсоветскому»)|Каждый из этих периодов представлен большим текстовым файлом в кодировке UTF-8, где в произвольном порядке находятся предложения исходных текстов, не содержит привязки к конкретным датам, подойдёт для обучения или тестирования|
|Корпус Тайга|5 биллионов слов|содержит метаданные о жанре и датировке|Содержит тексты только 20-21 веков, подходит для тестирования|
|The TOROT Treebank|примерно 230 000 вхождений|разделены на две группы старорусский и церковнославянский|может использоваться для тестирования|
