# Результаты сравнения моделей

Источник: `model_comparison.html` — переданный HTML-отчёт «Сравнение моделей:
жанр → период (25 лет)». Здесь приведена краткая сводка; матрицы ошибок,
подробные разрезы и списки ошибок находятся в HTML.

## Постановка эксперимента

- Тестовая выборка: **718 фрагментов**, **551 произведение**.
- Сравнивались шесть вариантов: `rubert`, `rubert_dict`, `tfidf`,
  `tfidf_dict`, `xlmr`, `xlmr_dict`.
- Схема: сначала предсказывается жанр, затем период при предсказанном жанре.
- Периоды: шесть 25-летних интервалов от 1800–1824 до 1925–1949.
- Основная метрика периода — QWK (quadratic weighted kappa).
- В отчёте отдельно показаны оценки по отдельным фрагментам и по произведениям.
  Для оценки по произведениям вероятности фрагментов одного произведения
  усредняются.

## Основной результат

<badge color="success">Лучший QWK по произведениям</badge> **RuBERT (`rubert`):
0.800 (95% ДИ 0.73–0.85).**

| Модель | QWK периода, произведения | Accuracy периода | ±1 период | Macro-F1 периода | Accuracy жанра |
|---|---:|---:|---:|---:|---:|
| `rubert` | **0.800** | 0.530 | 0.897 | 0.543 | 0.931 |
| `rubert_dict` | 0.790 | 0.512 | 0.886 | 0.521 | 0.931 |
| `tfidf_dict` | 0.762 | 0.454 | 0.864 | 0.462 | 0.922 |
| `xlmr` | 0.748 | 0.397 | 0.817 | 0.405 | 0.929 |
| `xlmr_dict` | 0.726 | 0.401 | 0.811 | 0.410 | 0.929 |
| `tfidf` | 0.707 | 0.450 | 0.824 | 0.451 | 0.922 |

По отдельным фрагментам лучший QWK также у `rubert`: **0.818**
(95% ДИ 0.75–0.87). Accuracy периода — 0.546, ±1 период — 0.893,
macro-F1 периода — 0.550.

## Что показало добавление словаря

| Пара | Уровень | QWK без словаря | QWK со словарём | Изменение |
|---|---|---:|---:|---:|
| RuBERT | произведения | 0.800 | 0.790 | −0.010 |
| TF-IDF | произведения | 0.707 | 0.762 | **+0.055** |
| XLM-R | произведения | 0.748 | 0.726 | −0.022 |
| RuBERT | фрагменты | 0.818 | 0.808 | −0.010 |
| TF-IDF | фрагменты | 0.732 | 0.775 | **+0.043** |
| XLM-R | фрагменты | 0.761 | 0.738 | −0.022 |

По тестовому отчёту словарная добавка улучшает TF-IDF, но не улучшает RuBERT
и XLM-R. В отчёте приведены доверительные интервалы разности; для RuBERT и
XLM-R они включают ноль. Для TF-IDF интервалы положительные в указанных
сравнениях.

Отдельно в отчёте указана оценка на validation с кросс-валидацией по авторам:
- `rubert_dict`: QWK 0.834 → 0.839, C=0.3;
- `tfidf_dict`: QWK 0.728 → 0.788, C=0.1;
- `xlmr_dict`: QWK 0.746 → 0.774, C=0.03.

Эти validation-оценки не следует смешивать с итоговыми test-метриками.

## Жанровая классификация

Accuracy жанра высокая у всех моделей — около 0.922–0.931. Для `rubert`
macro-F1 жанра на уровне произведений составляет 0.934. Основные путаницы,
показанные в матрицах ошибок, возникают между прозой и публицистикой;
поэзия определяется точнее.

## Ограничения и риски интерпретации

1. **Старая орфография (`old_orth`).** В отчёте отмечено, что доля фрагментов
   с `old_orth=true` различается по периодам: 31%, 26%, 37%, 38%, 17%, 5%.
   Это создаёт риск, что модель использует корреляцию с исходной орфографией,
   а не только стилевые признаки. При этом тексты нормализованы, а флаг
   отражает наличие старой орфографии в исходной странице.
2. **Accuracy периода заметно ниже QWK.** Модель часто ошибается на соседний
   период: для `rubert` по произведениям доля предсказаний в пределах ±1
   периода равна 0.897, но точное совпадение — 0.530. Поэтому QWK полезнее
   одной accuracy, однако не отменяет анализа матриц ошибок.
3. **Качество различается по жанрам и длине.** Например, на уровне фрагментов
   `rubert` показывает accuracy периода 0.496 для поэзии, 0.563 для прозы и
   0.579 для публицистики. Короткие фрагменты менее 100 слов представлены
   небольшой группой (31 пример), поэтому оценки для них нестабильны.
4. **Небольшой тест.** 718 фрагментов — ограниченный объём для выводов по
   отдельным подгруппам. Доверительные интервалы следует приводить вместе
   с точечными оценками.
5. **Отчёт не равен артефакту модели.** HTML содержит метрики и результаты,
   но не содержит веса моделей, токенизаторы, код обучения или код
   инференса. По одному отчёту нельзя восстановить работающую модель.

## Что делать с результатами в репозитории

- Сохранить полный HTML в `reports/model_comparison.html`, чтобы не потерять
  таблицы, интерактивные раскрывающиеся секции и подробности ошибок.
- Использовать этот Markdown как короткое описание результатов в README,
  отчёте по проекту и презентации.
- В качестве основного кандидата для дальнейшей интеграции рассматривать
  `rubert`, поскольку он лидирует по тестовому QWK на уровне произведений.
- Не удалять TF-IDF: `tfidf_dict` показывает, что словарь может быть полезен
  для более простой базовой модели.
- До интеграции запросить/добавить веса, токенизатор, конфигурацию,
  скрипты обучения и инференса. Также проверить влияние `old_orth` и дат,
  упомянутых в самом тексте, на предсказание.

**Текущий статус интеграции:** ни одна из шести моделей в приложенном архиве
не подключена к FastAPI. Веб-приложение продолжает использовать
`epoch_stub.py`.
