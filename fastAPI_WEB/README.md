# Веб-сервис Text Epoch

Веб-прототип для определения периода создания русского текста. Сценарий двухэтапный: **сначала определяется жанр (моделью или вручную пользователем), затем модель оценивает период написания** (шаг 25 лет). Найденные маркеры из жанровых словарей показываются как пояснение.

> Сервис работает с обученной моделью (`model_run/`, см. раздел «Подключение модели»). Если модель не найдена или не загрузилась, сервис автоматически переходит на словарную заглушку (`stub: true` в ответе).

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | FastAPI: маршруты, валидация запросов, история |
| `model_adapter.py` | загрузка обученной модели и функция `analyze(text, genre)`; при отсутствии модели — откат на заглушку |
| `era_pipeline.py` | код обучения/инференса моделей (нужен для загрузки модели) |
| `model_run/` | папка с обученной моделью (**не хранится в репозитории**, скачивается отдельно) |
| `nlp.py` | загрузка жанровых JSON-словарей, поиск маркеров, запасная словарная заглушка |
| `static/index.html` | интерфейс: (необязательный) выбор жанра → ввод текста → результат |
| `API.md` | описание текущего API |
| `test_api.py` | интеграционные проверки запущенного сервера |
| `requirements.txt` | Python-зависимости |

## Подключение модели

Файлы весов (≈1,4 ГБ) слишком велики для GitHub, поэтому в репозитории их нет.

1. Скачайте папку с моделью: [Google Диск](https://drive.google.com/drive/folders/1LLHrYofftgc2RpjRvbIEPY6sAuZKhza9?usp=sharing).
2. Положите её в `fastAPI_WEB/` под именем `model_run`, чтобы получилась структура:
   ```
   fastAPI_WEB/model_run/meta.json
   fastAPI_WEB/model_run/model/genre/...
   fastAPI_WEB/model_run/model/era/...
   fastAPI_WEB/model_run/model/tok/...
   ```
   Другой путь можно задать переменной окружения `MODEL_RUN`.
3. Запустите сервис (см. ниже) и откройте `/api/health`: при успешной загрузке будет `"model_loaded": true`, иначе в поле `error` указана причина.

Для работы модели нужны `torch`, `transformers`, `scikit-learn`, `joblib`, `numpy` (все в `requirements.txt`). Версия `scikit-learn` должна совпадать с версией, на которой модель обучалась.

## Запуск локально

Нужен Python 3.10 или новее.

```bash
cd fastAPI_WEB
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Установка и запуск:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте <http://127.0.0.1:8000/>. Документация API: <http://127.0.0.1:8000/docs>.

Проверка (в другом окне терминала, при работающем сервере):

```bash
python test_api.py
```

## Как работает анализ

С моделью (`stub: false`):

1. Текст режется на фрагменты, для каждого считаются вероятности жанра и периода; результаты усредняются по фрагментам.
2. Жанр определяет модель, либо его задаёт пользователь (поле `genre`; значение `auto` или отсутствие поля — определение моделью).
3. В ответе: жанр, период (25 лет), вероятность `score`, альтернативы, вероятности всех периодов `era_probs`, найденные маркеры `dated_markers`.

Без модели работает словарная заглушка:

1. Пользователь выбирает один из трёх жанров: поэзия, проза, публицистика.
2. `nlp.py` загружает соответствующий JSON из `markers/`.
3. Текст приводится к нижнему регистру, `ё` нормализуется в `е`; слова ищутся по точным словарным формам.
4. Для каждого совпадения берётся период `era` и сила маркера `log_ratio`.
5. Сумма свидетельств по периодам нормируется; наиболее поддержанный период показывается как результат.
6. Интерфейс выводит найденные маркеры и их позиции в исходном тексте.

Периоды, присутствующие в словарях: `1800-1849`, `1850-1899`, `1900-1924`, `1925-1944`. Если совпадений нет, сервис честно сообщает, что период не определён.

Заглушка — упрощённая эвристика: она не учитывает контекст, не распознаёт все словоформы и не должна трактоваться как научно достоверная датировка. Поле `stub` в ответе API позволяет клиенту отличить заглушку (`true`) от модели (`false`).

## API

### `GET /api/genres`

Возвращает допустимые жанры:

```json
{"genres": ["поэзия", "проза", "публицистика"]}
```

### `POST /api/analyze`

Запрос:

```json
{
  "genre": "проза",
  "text": "Сей человек долго смотрел на дорогу и думал о своей судьбе..."
}
```

- `genre`: `поэзия`, `проза`, `публицистика` или `auto` (необязательное поле; по умолчанию `auto` — жанр определяет модель);
- `text`: от 50 до 10 000 символов.

Ответ содержит `result` с жанром (`genre_source`: `user` или `model`), предполагаемым периодом, оценкой, альтернативами, вероятностями периодов `era_probs` и массивом `dated_markers`. `meta` содержит длину текста, выбранный жанр и время обработки.

### Служебные маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | состояние сервиса, число запросов, статус загрузки модели |
| GET | `/api/history?limit=10` | последние запросы в памяти процесса |
| GET | `/docs` | Swagger UI |
| GET | `/` | веб-интерфейс |
