# API веб-сервиса Text Epoch (заглушка)

## `GET /api/genres`

Список жанров, для которых имеются маркерные словари: `поэзия`, `проза`, `публицистика`.

## `POST /api/analyze`

Запрос JSON:

```json
{
  "genre": "проза",
  "text": "Текст длиной от 50 до 10 000 символов..."
}
```

Жанр обязателен и выбирается до датировки. Для поиска используются только маркеры выбранного жанра.

Успешный ответ имеет вид:

```json
{
  "ok": true,
  "result": {
    "genre": "проза",
    "genre_score": 1.0,
    "genre_source": "user",
    "period": "1800-1849",
    "period_range": {"from": 1800, "to": 1849},
    "granularity": 50,
    "score": 0.72,
    "alternatives": [],
    "dated_markers": [],
    "markers_found": 0,
    "marker_counts_by_period": {},
    "model_version": "markers-stub-0.1",
    "stub": true,
    "message": null
  },
  "meta": {"chars": 120, "genre": "проза", "took_ms": 1.2}
}
```

Пример иллюстрирует структуру, а не гарантированный результат конкретного текста. `genre_score: 1.0` означает, что жанр выбран человеком, а не распознан моделью. `score` — доля суммарного веса найденных маркеров, приходящаяся на выбранный период; это не калиброванная вероятность.

Периоды словарей: `1800-1849`, `1850-1899`, `1900-1924`, `1925-1944`. Если маркеры не найдены, `period` и `period_range` равны `null`, `score` равен `0`.

## Ограничения и ошибки

- Текст: 50–10 000 символов.
- Неизвестный жанр: HTTP 400.
- Текст короче минимума или длиннее максимума: HTTP 422 (валидация Pydantic).
- Поле `stub: true` обязательно для текущей реализации.
- Позиции `start` и `end` относятся к исходной строке.

Дополнительные маршруты: `GET /api/health`, `GET /api/history?limit=10`, `GET /docs`.
